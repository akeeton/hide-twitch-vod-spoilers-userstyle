# Hide Twitch VOD spoilers
Have you ever been watching an esports VOD but been spoiled by the remaining time shown in the video player?  It's the last match but there's not enough time left for a third map, so you know the winner of map one will win the match.  This userstyle hides the time elements and the current location of the seek bar to help avoid this kind of spoiler.

## Installation
1. Install the [Stylus](https://github.com/openstyles/stylus) browser extension via [Chrome Web Store](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) or [Firefox Browser Add-ons](https://addons.mozilla.org/firefox/addon/styl-us/).
2. Click this button to install the userstyle in Stylus: [![Install directly with Stylus](https://img.shields.io/badge/Install%20directly%20with-Stylus-00adad.svg)](https://github.com/akeeton/hide-twitch-vod-spoilers-userstyle/raw/refs/heads/main/hide-twitch-vod-spoilers.user.css)

## Customization
Click the Stylus extension icon and then click the gear icon next to the userstyle's name to customize it.  Various VOD player elements can be shown or hidden to your liking.
